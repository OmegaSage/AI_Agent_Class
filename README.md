These tasks mostly compose of four functions:
1) get file content - read the file and access the information contained inside
2) get files info - look inside directories, identify file types and sub-directories and do the same for each sub-folder
3) run python file - self-explanatory, python because it's relevant to the coursework this was designed around
4) write file - exactly what it sounds like, it can edit, re-write, and create files
